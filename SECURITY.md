# Security

This repository is a private pre-release. Tripcord has no hosted service.

## Reporting a vulnerability

Report vulnerabilities in Tripcord through GitHub private vulnerability reporting
on this repository (Security → Report a vulnerability).

Do not open a public issue for a security report.

The same channel is the placeholder for privately reporting malicious agent
configurations found in the wild, before a detection rule is published.

Private vulnerability reporting has to be enabled by a repository administrator.
Until it is, contact a maintainer directly.
